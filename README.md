# Project Omega

A small C++ project for experimenting with [raylib](https://www.raylib.com/) and building a basic 2D platformer.

## Requirements (Fedora)

```bash
sudo dnf install -y raylib raylib-devel gcc-c++ cmake git make
```

## Build and run

```bash
mkdir build && cd build
cmake ..
make
./bin/ProjectOmega
```
